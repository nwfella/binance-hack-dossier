Do notPanic-withdraw to an unverified destination

  • Stuck in a queue is recoverable. Sent to the wrong chain usually is not.
  • Send a small test amount first — one extra fee for real protection.
  • Confirm the specific network is open on Binance's status page; the headline statement is authoritative, per-network indicators lag.

AssumeYou are now a phishing target

  • Expect fake “Binance recovery”, “verify to unlock withdrawal” emails, SMS, DMs and paid search ads.
  • Binance will never DM first or ask for a password, 2FA code or seed phrase.
  • Navigate by typing the domain or using the app. Never via a link in a message.

CheckWhere your assets actually sit

  • Spot, Earn/staking, futures margin and Binance Alpha are different claims with different unwind mechanics.
  • Know which bucket you're in before you need to move.
  • Don't add leverage on the venue you're worried about.

AuditEIP-7702 delegations on your own wallets

  • An EOA can now be running someone else's code. Check every address you control for unexpected delegations.
  • Clear the delegation first, then rotate keys, then move funds.
  • Tools: Etherscan “delegated” indicators, Revoke.cash.

02 Incident brief

The short version. Section 6 has the forensics.

One leaked key, one persistent delegation

The attacker obtained the private key to Binance 14, one of the exchange's busiest payment wallets, and signed an EIP-7702 authorisation pointing it at attacker-deployed bytecode. The delegation persists until the wallet signs a replacement — so the wallet became a sweeper that forwarded every inbound deposit to the attacker, while Binance's own withdrawals kept flowing from it.

A 50-authorisation nonce spray

Because Binance 14's nonce was advancing with daily payouts, the attacker could not guess it — so he signed 50 authorisations across a contiguous nonce window in one type-4 transaction. Forty-nine failed. One matched. Nonce unpredictability is not a security control.

Then ten more wallets in twelve minutes

Within 12 minutes, ten more hot wallets on four chains sent to the same collection address — each as an ordinary transfer signed by the wallet's own key. The Ethereum delegation cannot explain the Bitcoin or Tron movements, which is why investigators describe a broader signing-key problem.

The wallets were the proof-of-reserves wallets

CoinDesk found the drained addresses are the same ones Binance publishes as backing customer assets. Its disclosed ether backing is an estimated 6% short until the stolen ETH is replaced — roughly 204,500 ETH that has to be bought back into the reserve.

Headlines are reproduced as-is, not summarised — including ones that report unverified numbers. The PDF is where claims are weighed and attributed.

Method. Compiled from primary reporting and on-chain analysis published 29–30 October 2026. Where independent parties disagree, both figures are shown with attribution rather than averaged.
